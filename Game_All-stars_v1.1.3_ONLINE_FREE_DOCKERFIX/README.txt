Game All-stars v1.1.0 ONLINE

追加機能:
- オンラインアカウント（新規登録 / ログイン / ログアウト）
- オンラインStore、所有権、ゲーム配信、更新
- ゲーム公開（EXE / HTML）
- フレンド登録、オンライン状態
- オンラインルーム、参加、ルームチャット
- オンラインランキング（ゲーム側から /api/score にスコア送信可能）
- オンライン対戦ロビーの基盤（ルームAPI / ポーリング型）

使い方:
1. npm install
2. npm run dev

インターネット公開:
- server/server.js をサーバーへ配置して `node server/server.js`。
- TCP 3180（または PORT 環境変数）の公開が必要です。
- HTTPS 配下で使う場合はリバースプロキシ等を利用してください。
- Launcher の Settings → サーバーURL を公開サーバーURLへ変更します。

注意:
この無料版は認証・ルーム・ランキングの基礎を内蔵したサンプル実装です。大規模公開サービスにする場合はDB、TLS、レート制限、メール認証、管理者権限、アンチチート等の追加が必要です。
